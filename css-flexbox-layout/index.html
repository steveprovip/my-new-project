Main Content

Đây là khu vực nội dung chính của trang web. Bố cục này được thiết lập bằng thuộc tính flex: 3; để chiếm 3 phần không gian chiều ngang trên màn hình Desktop.

Ưu điểm của bố cục CSS Flexbox:

  • Dễ dàng căn chỉnh: Hỗ trợ căn giữa, phân bổ khoảng cách đồng đều với justify-content và align-items.
  • Linh hoạt theo tỷ lệ: Sử dụng cú pháp rút gọn flex: 3 và flex: 1 để phân chia tỷ lệ cột trực quan.
  • Responsive đơn giản: Chỉ cần thay đổi flex-direction: column trong Media Queries là giao diện tự động thích ứng với thiết bị di động.
