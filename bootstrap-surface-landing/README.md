# [Bài tập] Xây dựng Landing Page Microsoft Surface

Dự án thiết kế lại trang Landing Page Microsoft Surface ([Microsoft Surface Store](https://www.microsoft.com/en-us/store/b/surface)) hoàn chỉnh bằng Bootstrap 5 theo tiêu chuẩn Responsive (CodeGym).

## 1. Cấu trúc trang web
- **Microsoft Navbar**: Thanh điều hướng chuẩn giao diện Microsoft gồm logo thương hiệu, menu danh mục (Surface Pro, Surface Laptop, Surface Book, Accessories, Deals có dropdown) và các icon Tìm kiếm, Giỏ hàng, Tài khoản.
- **Hero Section**: Khối quảng bá Surface Pro 9 mới với tiêu đề lớn, phụ đề, nút CTA "Shop now", "Compare devices" và hình ảnh thiết bị trung tâm.
- **Quick Links Category Grid**: Hàng biểu tượng 6 danh mục sản phẩm Surface chính (Pro, Laptop, Book, Studio, Accessories, Deals).
- **Featured Products (Grid 4 Cột)**: Lưới sản phẩm Surface Family (`col-12 col-sm-6 col-lg-3`) gồm Surface Pro 9, Surface Laptop 5, Surface Laptop Studio, Surface Go 3 kèm giá, badge phân loại và nút chọn mua.
- **Accessories Section**: Giới thiệu phụ kiện Surface Bút cảm ứng, Bàn phím Signature và Chuột công thái học.
- **Value Propositions**: 4 cam kết dịch vụ của Microsoft Store (Giao hàng miễn phí, 60 ngày đổi trả, cam kết giá tốt nhất, hỗ trợ kỹ thuật 1-1).
- **Microsoft Footer**: Chân trang đa cột đầy đủ các liên kết chính sách và thông tin bản quyền.

## 2. Tiêu chuẩn Bootstrap áp dụng
- Tận dụng tối đa các class có sẵn của Bootstrap: Grid System (`row`, `col-lg-3`, `col-lg-6`, `col-md-2`), Cards, Dropdowns, Flex utilities, Buttons.
- Hạn chế tối đa CSS tùy biến nhằm tuân thủ đúng yêu cầu của đề bài.

## 3. Cách mở và kiểm tra
Mở trực tiếp file `index.html` trong trình duyệt web để xem giao diện hoàn chỉnh.
