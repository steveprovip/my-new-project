# [Bài tập] Tạo Landing Page với Bootstrap và Hình Ảnh

Dự án Landing Page chuyên nghiệp sử dụng Bootstrap Containers, Grid System, Buttons và Images (CodeGym).

## 1. Các thành phần chính của trang
- **Banner (Hero Section)**: Hình ảnh nền chất lượng cao với lớp phủ tối, tiêu đề trang lớn và nút bấm Call to Action (`btn btn-primary btn-lg`).
- **Giới thiệu**: Một hàng (`row`) kết hợp hình ảnh chuẩn responsive (`img-fluid`, bo góc) và cột nội dung mô tả chi tiết sản phẩm/dịch vụ (`col-12 col-lg-6`).
- **Danh sách tính năng**: Một hàng (`row`) gồm 4 cột (`col-12 col-md-6 col-lg-3`), mỗi cột hiển thị icon nổi bật, tiêu đề và phần mô tả ngắn gọn.
- **Kêu gọi hành động (CTA Section)**: Khối màu nổi bật với nút bấm kích thước lớn `Đăng ký ngay` và `Xem thêm`.
- **Footer**: Bản quyền và thông tin cuối trang.

## 2. Tiêu chuẩn Bootstrap áp dụng
- **Bootstrap Grid**: Sử dụng hệ thống lưới 12 cột linh hoạt (`row`, `col-12`, `col-md-6`, `col-lg-3`).
- **Bootstrap Images**: Class `img-fluid` giúp hình ảnh tự động co giãn theo khung chứa, không bị tràn viền trên màn hình điện thoại.
- **Bootstrap Buttons**: `btn-primary`, `btn-outline-light`, `btn-lg` tạo điểm nhấn chuyển đổi người dùng.

## 3. Cách mở và kiểm tra
Mở trực tiếp file `index.html` trong trình duyệt web để trải nghiệm giao diện hoàn chỉnh trên mọi kích thước màn hình.
