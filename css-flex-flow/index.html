[Thực hành] CSS | flex-flow Property

Tìm hiểu thuộc tính viết tắt (shorthand) cho flex-direction và flex-wrap

Lý thuyết tóm tắt

Thuộc tính flex-flow trong CSS là thuộc tính viết tắt (shorthand) kết hợp giữa hai thuộc tính cơ bản của Flex Container:

  • flex-direction: Xác định hướng sắp xếp các item (trục chính - main axis: row, row-reverse, column, column-reverse).
  • flex-wrap: Xác định các item có được bọc xuống dòng hay không (nowrap, wrap, wrap-reverse).
flex-flow: <flex-direction> <flex-wrap>;

Giá trị mặc định: flex-flow: row nowrap;

Ví dụ 1: flex-flow: row nowrap;
