[Bài đọc] Cách tổ chức thư mục và file SASS hiệu quả

Mô hình kiến trúc 7-1 SASS Pattern chuẩn quốc tế giúp tối ưu hóa khả năng bảo trì, mở rộng và tái sử dụng code trong các dự án Frontend chuyên nghiệp.

Cấu trúc cây thư mục 7-1 SASS đã khởi tạo

📂 sass/ │── 📄 main.scss # File SASS chính (import tất cả 7 folder bên dưới) │── 📂 abstracts/ # Chứa biến, mixins, functions │ │── 📄 _variables.scss # Colors, fonts, spacing │ │── 📄 _mixins.scss # Nhóm CSS tái sử dụng (flex, responsive) │ │── 📄 _functions.scss # Các hàm xử lý (rem, px) │── 📂 base/ # Thiết lập nền tảng dự án │ │── 📄 _reset.scss # Reset CSS │ │── 📄 _typography.scss # Font chữ, tiêu đề │ │── 📄 _global.scss # Quy tắc chung │── 📂 layout/ # Bố cục tổng thể trang web │ │── 📄 _header.scss # Header │ │── 📄 _footer.scss # Footer │ │── 📄 _grid.scss # Hệ thống lưới │── 📂 components/ # Các thành phần UI độc lập │ │── 📄 _buttons.scss # Button styles & modifier │ │── 📄 _cards.scss # Card UI │── 📂 pages/ # Style riêng biệt cho từng trang │ │── 📄 _home.scss # Trang chủ │ │── 📄 _about.scss # Giới thiệu │ │── 📄 _contact.scss # Liên hệ │── 📂 themes/ # Chế độ màu sắc │ │── 📄 _light.scss # Giao diện sáng │ │── 📄 _dark.scss # Giao diện tối │── 📂 vendors/ # Thư viện bên ngoài │ │── 📄 _bootstrap.scss # Biến tùy biến Bootstrap │ │── 📄 _custom.scss # Ghi đè vendor CSS

✅ Tóm tắt giá trị đạt được:

  • Quản lý logic rõ ràng: Mỗi file đảm nhận đúng 1 nhiệm vụ duy nhất (Single Responsibility Principle).
  • Dễ dàng scale: Thêm trang mới chỉ cần tạo thêm file vào thư mục pages/, thêm component vào components/.
  • Dễ dàng biên dịch: Chỉ cần biên dịch duy nhất file main.scss ra file style.css thành phẩm.
