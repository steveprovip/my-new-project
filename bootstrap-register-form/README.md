# [Bài tập] Thiết kế Trang Đăng Ký với Bootstrap Forms

Bài tập thiết kế form đăng ký tài khoản người dùng chuyên nghiệp bằng Bootstrap 5 Forms, Controls và Buttons (CodeGym).

## 1. Các trường thông tin được triển khai
Gồm đầy đủ 8 thành phần theo yêu cầu:
1. **Họ và tên**: Thẻ input với class `form-control`.
2. **Email**: Thẻ input email với hướng dẫn `form-text text-muted`.
3. **Mật khẩu**: Input type password.
4. **Xác nhận mật khẩu**: Input type password, đặt song song trên desktop (`row` & `col-md-6`) và xếp dọc trên mobile (`col-12`).
5. **Giới tính**: Radio button inline (`form-check form-check-inline`).
6. **Sở thích**: Checkbox đa lựa chọn (`form-check form-check-inline`).
7. **Quốc gia**: Thẻ select dropdown với class `form-select`.
8. **Nút Submit**: Nút bấm nổi bật kích thước lớn `btn btn-primary` kèm hiệu ứng `shadow-sm`.

## 2. Tiêu chuẩn Bootstrap áp dụng
- **Form Controls**: Sử dụng `form-control`, `form-select`, `form-check-input`.
- **Text Elements**: Định dạng chữ phụ chú với `text-muted`, `small`, canh lề với `text-center`.
- **Responsive Layout**: Form tự động co giãn tối ưu từ màn hình điện thoại nhỏ đến màn hình máy tính lớn (`max-width: 620px; width: 100%`).

## 3. Cách xem
Mở file `index.html` trong trình duyệt web để trải nghiệm giao diện form đăng ký.
