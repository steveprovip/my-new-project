[Thực hành] Tạo Navbar với Bootstrap

Thực hành thanh điều hướng Responsive chuyên nghiệp sử dụng Bootstrap 5.3.0 CDN

Xem tài liệu Bootstrap Docs

📌 Các class Bootstrap đã sử dụng

  • navbar navbar-expand-lg: Hiển thị full trên desktop (>=992px), thu gọn thành burger menu trên mobile.
  • navbar-dark bg-dark: Giao diện nền tối với màu chữ tương phản.
  • navbar-brand: Logo hoặc tên trang web.
  • navbar-toggler & navbar-toggler-icon: Nút bấm mở menu trên điện thoại.
  • dropdown-toggle & dropdown-menu: Menu con dạng thả xuống.

🚀 Kiểm tra tính năng

Thanh điều hướng hoàn toàn sẵn sàng và hỗ trợ các tính năng:

<!-- Bootstrap 5.3.0 JS Bundle -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

Thử bấm vào mục Services để mở Dropdown hoặc thu nhỏ cửa sổ trình duyệt xuống dưới 992px để xem nút Hamburger hoạt động mượt mà.
