[Bài đọc] Hướng dẫn cài đặt SASS bằng npm & SASS CLI

Trang hướng dẫn trực quan & thực hành biên dịch tệp SCSS sang CSS bằng SASS CLI

1. Kiểm tra Node.js và npm

SASS được quản lý và cài đặt tối ưu thông qua npm (Node Package Manager). Kiểm tra phiên bản bằng lệnh:

node -v && npm -v

Kết quả thực tế trên máy hiện tại: Node.js v24.15.0, npm 11.12.1 (đã sẵn sàng).

2. Cài đặt SASS toàn cục (Global) bằng npm

Chạy lệnh cài đặt bản chính thức Dart SASS vào hệ thống:

npm install -g sass

Kiểm tra phiên bản sau khi cài đặt:

sass --version

3. Biên dịch SCSS sang CSS bằng SASS CLI

Cú pháp chuyển đổi 1 file đơn lẻ từ SCSS sang CSS chuẩn:

sass scss/styles.scss css/styles.css

4. Kích hoạt chế độ tự động theo dõi (Watch Mode)

Tự động phát hiện thay đổi trong thư mục và biên dịch ngay lập tức mà không cần gõ lại lệnh:

sass scss/:css/ --watch

5. Xử lý lỗi quyền truy cập "Set-ExecutionPolicy" trên Windows

Nếu gặp lỗi không thể chạy script trên PowerShell, mở PowerShell với quyền Run as Administrator và thực hiện:

Set-ExecutionPolicy Unrestricted -Scope CurrentUser
