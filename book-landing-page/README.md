# Dự Án Web Giới Thiệu Sách (Book Landing Page)

Dự án trang web tĩnh giới thiệu về sách chuẩn Responsive trên mọi thiết bị, sử dụng thư viện Bootstrap, HTML5, CSS3 và Font Awesome (CodeGym).
Mã nguồn tham khảo mở rộng từ: [hoanv7169/bootstrap-demo](https://github.com/hoanv7169/bootstrap-demo).

## 1. Các phần tử bắt buộc trong trang (Đầy đủ 7 phần)
1. **Header & Book Overview**: Thanh điều hướng Navbar dạt phải, tiêu đề sách `EXCITING ADVENTURE`, tên tác giả `DAILY TUITION`, nút mua nhanh và ảnh bìa sách 3D.
2. **Author**: Giới thiệu về tác giả `Mr. Devid Smith` kèm chân dung và tiểu sử chuyên môn.
3. **Features**: Các số liệu thống kê nổi bật (Happy Clients, Copies Sold, Reviews, Community) trên nền cover ấn tượng.
4. **Prices**: Bảng giá 3 gói lựa chọn (*PDF Version, E-book Bundle, Print Copy*) dạng Card chuyên nghiệp.
5. **Download**: Khối kêu gọi tải ứng dụng di động & máy tính để bàn (Desktop App cho Windows/macOS & Mobile App cho iOS/Android).
6. **Reader’s Say**: Cảm nhận đánh giá của độc giả có tích hợp Bootstrap Carousel trình chiếu các đánh giá uy tín.
7. **Footer**: Thông tin About Us, Form đăng ký nhận bản tin Newsletter và các icon mạng xã hội Follow Us.

## 2. Tính năng Responsive
- Tương thích tốt trên toàn bộ các kích thước màn hình: Desktop (≥ 992px), Tablet (768px – 991px), Mobile (< 768px).
- Navbar tự động thu gọn thành nút icon burger khi xem trên màn hình nhỏ.

## 3. Cách xem
Mở trực tiếp file `index.html` trong trình duyệt web để trải nghiệm.
